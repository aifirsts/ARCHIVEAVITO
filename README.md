# Beauty Supply — архивная витрина и аудит источников

**Сайт магазина: [`site/public/`](site/public/index.html)** — собственная вёрстка, 16 страниц, 150 изображений, адаптивные карточки, галереи с пометкой источника, поиск, фильтры, сортировка, клавиатурная навигация. Собирается командой `python site/build.py`, документация — [`site/README.md`](site/README.md).

Витрина использует 14 товаров из архива профиля Avito: 53 фото-превью профиля, 74 миниатюры и 38 крупных JPEG из 13 отдельных объявлений, 5 кадров и 1 фото из архива `Attachments-Avitos.zip`, 13 отдельно помеченных изображений с официальных страниц брендов, а также **3 фото и 5 свежих цен продавца из сообщений от 28.10.2026** (архив `Attachments-Fw_ 27.10 avito.zip`).

**Статус данных:** владелец подтвердил в переписке, что профиль Avito и магазин принадлежат ему. Источники — снимок HTML в `usaforyou/MANUS1/Авито 14.zip`, три ZIP отдельных карточек `PART1_HTMLS.zip`, `PART_2.zip`, `PART3.zip`, два поздних ZIP с повторами, `Attachments-Avitos.zip` (проверен 26.10.2026) и **`Attachments-Fw_ 27.10 avito.zip`** (коммит `68d7c1f`, SHA-256 `216adc3c…bc349c`, проверен 28.10.2026: 7 расшифрованных сообщений продавца и 3 фото 960×1280). Текущие цены, наличие, подлинность отдельных товаров и права на изображения брендов **не проверены**. Это не платёжный сайт. Для заказа переходите к объявлению и уточняйте условия у продавца.

**Слой 28.10.2026:** продавец прислал свежие цены (Max face cream 11 500 ₽, Max eye cream 6 800 ₽, SPF 30 мойсчерайзер 4 900 ₽, Biotech MD cream 10 400 ₽, Biotech MD serum 11 500 ₽). Две из них соответствуют архивным объявлениям `8166255881` и `8230842563` и показаны на их карточках отдельным блоком с цитатой и дельтой к архивной цене; остальные три — новые предложения без архивной карточки. Сыворотка Power-C **не объединена** с архивной «Restoring Youth Serum». Подробности — в [`avito_audit/ATTACHMENTS_FW_2026_10_28.md`](avito_audit/ATTACHMENTS_FW_2026_10_28.md).

**Для разработчика:** контракт данных — [`handoff/README.md`](handoff/README.md) и [`handoff/storefront.json`](handoff/storefront.json); готовый сайт — [`site/`](site/README.md). Пакет регенерируется командой `python handoff/generate.py`, сайт — `python site/build.py`; всё проверяется 47 офлайн-тестами, браузерным smoke-тестом и GitHub Actions.

**[Финальный аудит и дальнейшие шаги](FINAL_AUDIT.md)** — сводная проверка всех восьми ZIP в `MANUS1` и готовности каталога `MATRIX2`. Подробная проверка локальных файлов — в [`REPOSITORY_AUDIT.md`](REPOSITORY_AUDIT.md); [два поздних ZIP](avito_audit/ADDITIONAL_ZIP_REVIEW.md) повторяют карточки часов `8296456393` и **одного** чехла `8102096652`, но не содержат страницу лота «2 шт» `8350792227` или JPEG позиции № 4 часов. Это проверка **целостности архива**, а не подтверждение текущего состояния объявлений.

## Публикация сайта

Рабочий процесс [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) при пуше в `main` (или запуске вручную — `workflow_dispatch`) прогоняет офлайн-тесты, собирает `site/build.py` и публикует **только `site/public`** как сайт GitHub Pages. Публичный адрес после включения — `https://aifirsts.github.io/MATRIX2/`.

**Статус на 28.10.2026: публикация не выполнена** — у аккаунта владельца репозитория Actions заблокирована биллингом («account is locked due to a billing issue»), а токену этой сессии недоступны API настроек репозитория и GitHub Pages (403 «Resource not accessible by integration»). Готовый сайт лежит в `site/public` (16 страниц, 150 изображений) и опубликовывается одной командой после разблокировки: переименовать ветку `MAIN2` в `main` (или просто сделать её основной) и запустить `deploy.yml` вручную либо пушем. Публиковать корень репозитория нельзя: в нём лежат исследовательские JSON, отзывы и исходные манифесты.

## Локальный просмотр

```bash
python handoff/generate.py
python site/build.py
cd site/public && python -m http.server 8080 --bind 0.0.0.0
```

Откройте `http://localhost:8080/`. Для статического хостинга публикуйте **только `site/public`** (это делает `deploy.yml`), не корень репозитория.

Проверки:

```bash
python -m unittest discover -s tests -v     # 47 офлайн-тестов (архив, пакет, сборка, ссылки, хеши, новый слой)
node --check site/src/app.js
python site/tests/browser_smoke.py          # Chromium: десктоп 1440×950 и мобильный 390×844
```

Дополнительно: axe-core (0 нарушений на страницах × 2 ширины), сверка всех 150 опубликованных изображений по SHA-256 — в CI и офлайн-тестах.

## Перед коммерческой публикацией

Подтвердить у владельца каждого товара актуальное наличие, цену, состояние, состав, фото и возможность законной продажи; проверить косметику/SPF, документацию, подлинность и условия заказа (свежие цены от 28.10.2026 — заявления продавца в переписке, их тоже нужно подтвердить). Официальные свойства линеек нельзя выдавать за доказанные свойства конкретных товаров без проверки этикеток. Изображения брендов принадлежат правообладателям: право на дальнейшее коммерческое использование необходимо согласовать отдельно.
