# Beauty Supply — архивная витрина и аудит источников

**Новый сайт магазина: [`site/public/`](site/public/index.html)** — собственная вёрстка и реализация с нуля, 14 товаров, адаптивные карточки, галереи с пометкой источника, поиск, фильтры, клавиатурная навигация. Собирается командой `python site/build.py`, документация — [`site/README.md`](site/README.md).

Файлы `index.html`, `styles.css`, `catalog.js` в корне — **архивный прототип** предыдущего этапа, а не новый сайт; он оставлен для сверки содержимого.

Витрина использует 14 товаров из архива профиля Avito: 53 фото-превью профиля, 74 миниатюры и 38 крупных JPEG из 13 отдельных объявлений, 5 кадров и 1 фото из нового архива `Attachments-Avitos.zip`, а также 13 отдельно помеченных изображений с официальных страниц брендов.

**Статус данных:** владелец подтвердил в переписке, что профиль Avito и магазин принадлежат ему. Источники — снимок HTML в `usaforyou/MANUS1/Авито 14.zip`, три ZIP отдельных карточек `PART1_HTMLS.zip`, `PART_2.zip`, `PART3.zip` от 26.10.2026, а также **новый архив `Attachments-Avitos.zip`** (коммит `cf1c74b4a623ad22e7cedd5180aee98571261b1b`, SHA-256 `7d1eca79…b5d6d0`), проверенный 26.10.2026: 8 мобильных скриншотов галереи часов и 2 PDF-печати страниц. Текущие цены, наличие, подлинность отдельных товаров и права на изображения брендов **не проверены**. Это не платёжный сайт. Для заказа переходите к объявлению и уточняйте условия у продавца.

**Для разработчика:** контракт данных — [`handoff/README.md`](handoff/README.md) и [`handoff/storefront.json`](handoff/storefront.json); готовый сайт — [`site/`](site/README.md). Пакет регенерируется командой `python handoff/generate.py`, сайт — `python site/build.py`; и то, и другое проверяется 37 офлайн-тестами, браузерным smoke-тестом и GitHub Actions.

**[Финальный аудит и дальнейшие шаги](FINAL_AUDIT.md)** — сводная проверка всех шести ZIP в `MANUS1` и готовности каталога `MATRIX2`. Подробная проверка локальных файлов — в [`REPOSITORY_AUDIT.md`](REPOSITORY_AUDIT.md); [два поздних ZIP](avito_audit/ADDITIONAL_ZIP_REVIEW.md) повторяют карточки часов `8296456393` и **одного** чехла `8102096652`, но не содержат страницу лота «2 шт» `8350792227` или JPEG позиции № 4 часов. Это проверка **целостности архива**, а не подтверждение текущего состояния объявлений.

## Файлы

- `site/` — **новый сайт**: `src/site.css`, `src/app.js`, `build.py`, собранный `public/`; см. [`site/README.md`](site/README.md).
- `avito_audit/attachments_avitos/` + [`avito_audit/ATTACHMENTS_2026_10_25.md`](avito_audit/ATTACHMENTS_2026_10_25.md) — разбор нового архива: 10 записей, хеши, классификация (лот / реклама / аватар / рекомендации), найденный кадр № 4 часов и фото лота «2 шт».
- `avito_audit/check_attachments_zip.py` — воспроизводимая проверка `Attachments-Avitos.zip` (безопасный разбор, извлечение кадров, манифест).
- `index.html`, `styles.css`, `catalog.js` — **архивный прототип** предыдущего этапа без сборки.
- [`catalog.json`](catalog.json) — 14 карточек (цены из снимка, локальные фото, ссылка Avito, расширенные характеристики, применение и ингредиенты производителя, уровень соответствия).
- [`official_assets/`](official_assets/) — 13 локальных иллюстраций производителей (для 13 карточек); [`manifest.json`](official_assets/manifest.json) фиксирует происхождение, хеши и оговорки о вариантах; [`INGREDIENTS.md`](official_assets/INGREDIENTS.md) — опубликованные INCI семи средств IMAGE. Официальное изображение MoonSwatch не удалось локально сохранить.
- [`avito_audit/images/`](avito_audit/images/) — 53 JPEG 208×208 из архивного HTML, разложены по ID объявления. В старом архиве два фото часов были только ссылками, в новых ZIP часть ракурсов присутствует; одна позиция новой галереи часов всё ещё только внешняя ссылка.
- [`avito_audit/attachments_avitos/manifest.json`](avito_audit/attachments_avitos/manifest.json) — 10 записей нового архива, хеши, классификация 142 изображений из PDF и 8 обрезок шапок с «N из 9».
- [`avito_audit/item_pages/`](avito_audit/item_pages/) — `data.json` с полным текстом продавца, характеристиками, двумя версиями описания, архивными ценами и метаданными галерей 13 товаров; `images/<id>/` — 112 JPEG из новых архивов (74 миниатюры и 38 крупные копии); [`REPORT.md`](avito_audit/item_pages/REPORT.md) — методика, таблица всех 14 товаров и ограничение: для `8350792227` отдельной карточки нет.
- [`avito_audit/images_manifest.json`](avito_audit/images_manifest.json) — 55 ссылок на миниатюры с архивными путями и SHA-256 локальных файлов.
- [`avito_audit/OFFICIAL_RESEARCH.md`](avito_audit/OFFICIAL_RESEARCH.md) — сопоставление всех 14 товаров с официальными страницами, оговорки о вариантах, подробная методика и источники.
- [`avito_audit/REPORT.md`](avito_audit/REPORT.md) — происхождение ZIP и архивный аудит; `products.csv` и `snapshot.json` — машиночитаемый реестр и сохранённые факты.
- `avito_audit/extract_images.py` — извлечение старых превью; `avito_audit/extract_item_pages.py` — извлечение новых страниц и JPEG по трём ZIP с проверкой SHA-256; `avito_audit/sync_item_catalog.py` — обновление каталога без перезаписи данных производителя. Зависимости: `avito_audit/requirements.txt`. Исходные ZIP, HTML, JS и CSS из них сюда не копировались.

## Локальный просмотр

```bash
python handoff/generate.py
python site/build.py
cd site/public && python -m http.server 8080 --bind 0.0.0.0
```

Откройте `http://localhost:8080/`. Для статического хостинга публикуйте **только `site/public`**, не корень репозитория: в корне лежат исследовательские JSON, отзывы и исходные манифесты. GitHub Pages в этой сессии **не включён** (API отдаёт 404, настройки репозитория токену недоступны), поэтому публичного домена нет; CI собирает каталог как артефакт `beauty-supply-site`.

Проверки:

```bash
python -m unittest discover -s tests -v     # 37 офлайн-тестов (архив, пакет, сборка, ссылки, хеши, absence of reviews)
node --check catalog.js && node --check site/src/app.js
python site/tests/browser_smoke.py          # Chromium: десктоп 1440×950 и мобильный 390×844
```

Дополнительно в этой сессии: axe-core (0 нарушений на 5 страницах × 2 ширины), сверка всех 147 опубликованных изображений по SHA-256 и визуальный просмотр скриншотов.

## Перед коммерческой публикацией

Подтвердить у владельца каждого товара актуальное наличие, цену, состояние, состав, фото и возможность законной продажи; проверить косметику/SPF, документацию, подлинность и условия заказа. Официальные свойства линеек нельзя выдавать за доказанные свойства конкретных товаров без проверки этикеток. Изображения брендов принадлежат правообладателям: право на дальнейшее коммерческое использование необходимо согласовать отдельно.
