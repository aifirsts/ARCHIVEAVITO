## Существенные ограничения, оставшиеся после проверки

1. `8350792227`: среди трёх новых ZIP **нет отдельной карточки**. Из первого архива доступны короткий фрагмент описания «Для Дениса.» и одно превью; сведения о втором чехле, количестве и составе лота не подтверждены.
2. Среди 75 позиций галерей новых карточек для одной позиции часов `8296456393` есть только удалённая ссылка без JPEG в ZIP. Две ссылки на миниатюры часов отсутствовали и в первом архиве; остальные архивные снимки часов извлечены. Отсутствующие файлы не подменены чужими изображениями.
3. В шести объявлениях JSON-LD `Offer.price` совпадает с **зачёркнутой**, а не видимой ценой. На витрине приведена **видимая архивная** цена; обе версии доступны для аудита. Архивные значки наличия, даты и число просмотров нельзя считать текущими.
4. Архивное фото четырёх коробок MoonSwatch не доказывает, что продаются четыре часов по одной цене. Фотография упаковки Hourglass указывает на оттенок Mood Exposure, но не доказывает подлинность продаваемого экземпляра.
5. Официальные изображения — отдельные **иллюстрации линеек**; официальное изображение MoonSwatch не сохранено, для часов доступны только фото из архивов. Использование снимков брендов и продавца для коммерческой публикации требует проверки прав. Состав, сроки годности, комплектация, собственность на лоты, реальные цены и наличие не проверены.

**Вывод:** внутренние файлы репозитория согласованы и витрина технически работает, но это архивный исследовательский каталог, а не подтверждённый актуальный магазин. Для утверждения текущего состояния необходима проверка у владельца и/или действующих объявлений.
