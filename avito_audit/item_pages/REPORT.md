**Разночтения:** в шести объявлениях `schema.org/Offer` содержит **зачёркнутую** цену, а не цену, видимую покупателю; показанная в каталоге архивная цена сверена с видимым HTML и более ранним профилем. Даты объявлений в отдельных страницах могут отличаться от строк в профиле; источники не слиты, год видимой даты отдельно не задан. Значки «в наличии» в HTML не подтверждают наличие сегодня. Описания и характеристики — заявления продавца; не подтверждают ни медицинские/косметические эффекты, ни оригинальность, ни состав конкретного экземпляра.

В HTML продавец просит уточнять модели и цены. См. оговорки в [`OFFICIAL_RESEARCH.md`](../OFFICIAL_RESEARCH.md).

## Воспроизведение

```bash
python -m venv .venv
.venv/bin/pip install -r avito_audit/requirements.txt
.venv/bin/python avito_audit/extract_item_pages.py /path/to/PART1_HTMLS.zip /path/to/PART_2.zip /path/to/PART3.zip
python avito_audit/sync_item_catalog.py
python -m unittest discover -s tests -v
```

Экстрактор проверяет SHA-256 ZIP, продавца и 13 ожидаемых ID. ZIP и страницы целиком не копируются в этот репозиторий; исключены изображения похожих товаров, реклама, JS и CSS. Повторный запуск обновляет извлечённые файлы; ручные заключения об официальном соответствии не переносятся из автоматически полученных описаний.
