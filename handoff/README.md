# Передача данных другому Manus AI: новый сайт магазина с нуля

**Задача следующему агенту:** построить **новый** сайт магазина по данным этого репозитория. Существующие `index.html`, `styles.css`, `catalog.js` — архивный прототип для ориентира и проверки содержимого, **не обязательный макет и не готовый продакшен-сайт**. Владелец подтвердил в переписке, что Avito-магазин его; это не подтверждает автоматически актуальные остатки/цены, подлинность каждой единицы или права на фото производителей.

## Начните с этих файлов

1. [`storefront.json`](storefront.json) — готовый **машиночитаемый пакет для фронтенда**, 14 товаров, текст продавца, архивные цены, галереи, сведения брендов. Все пути к файлам — относительно корня репозитория. `schema_version: 1`. Файл **генерируется** из первоисточников командой `python handoff/generate.py`; не правьте его вручную.
2. [`../catalog.json`](../catalog.json) — канонический реестр товаров с сохранёнными полями профиля, официальными сведениями и подборкой фото для старого прототипа. Изменения данных вносить здесь и в профильные источники с описанием происхождения; потом регенерировать пакет.
3. [`../avito_audit/item_pages/data.json`](../avito_audit/item_pages/data.json) — 13 полных отдельных архивных HTML-карточек в нормализованном виде: оба варианта текста, характеристики, две версии цены, просмотры, бейджи, источники, 75 упорядоченных позиций галереи с SHA-256 и размерами. Исходные HTML находятся в ZIP исходного [`usaforyou/MANUS1`](https://github.com/usaforyou/MANUS1); ZIP не включены в этот репозиторий.
4. [`../avito_audit/snapshot.json`](../avito_audit/snapshot.json) и [`../avito_audit/images_manifest.json`](../avito_audit/images_manifest.json) — более ранняя страница профиля: 14 карточек, краткие фрагменты текста, 53 JPEG-превью и две отсутствующие ссылки часов. Отзывы в `snapshot.json` не являются готовым блоком отзывов для новой витрины; не публикуйте их автоматически.
5. [`../official_assets/manifest.json`](../official_assets/manifest.json), [`../official_assets/INGREDIENTS.md`](../official_assets/INGREDIENTS.md) и [`../avito_audit/OFFICIAL_RESEARCH.md`](../avito_audit/OFFICIAL_RESEARCH.md) — 13 иллюстраций с сайтов брендов, исследования 14 линеек и 7 списков INCI; это **не** доказательство подлинности экземпляра, разрешения на использование официальных фото или наличия товара.
6. [`../FINAL_AUDIT.md`](../FINAL_AUDIT.md) — итоговая проверка шести ZIP, известные пропуски и порядок подтверждения с владельцем.

## Контракт пакета `storefront.json`

- `products[]`: 14 уникальных Avito ID. `title_from_seller`, `category_from_snapshot`, `avito_url` — утверждения/наименования из архивного объявления. `seller_profile_from_archive` — публичный ID, имя и ссылка профиля; `source_archives_sha256` — контрольные суммы четырёх ZIP, из которых составлен пакет.
- `archived_listing.price_rub`, `old_price_text`, `discount_text`, `location_text`, `profile_date_text` — **только снимок**, не live-данные. `item_page_date_text` может отличаться от строки в профиле; не сливайте источники. `schema_offer_price_rub` в **6 товарах** равен зачёркнутой цене, а не видимой: для исторической цены используйте `price_rub`.
- `archived_listing.seller_description_normalized` — полный текст продавца из JSON-LD, `seller_description_html_transcription` — текст из видимого HTML (может содержать Unicode-омоглифы). `description_profile_excerpt` — краткий фрагмент первой страницы; у товара без отдельной страницы полный текст равен `null`. `attributes_from_seller`, бейдж наличия и просмотры — не независимая экспертиза.
- `media.listing_gallery[]` — **порядок** фото отдельной карточки. Для показа выбирайте `large.path`, иначе `thumbnail.path`; `remote_url_only: true` означает **отсутствующий локальный файл**; `missing_remote_url_for_audit` и `avito_share_url_for_audit` — только происхождение, **не** адреса для показа вместо сохранённого JPEG. `profile_previews[]` — отдельные 53 фотографии более раннего профиля; при показе маркируйте другой источник. Каждый локальный объект `asset` имеет `sha256`, `bytes`, а когда известно — `dimensions`.
- `media.manufacturer_illustration` и `manufacturer_research` — отдельные материалы брендов. Показывайте с подписью «Иллюстрация производителя», **не как фотографию лота**. У часов официального локального фото нет; одна и та же иллюстрация Speck используется для двух разных ID чехлов.
- Идентификаторы статусов в `storefront.json`: `status: archived_research_not_live_inventory`; `individual_page_saved` — есть/нет отдельной сохранённой карточки. Для последующих подтверждений цен/остатков создайте **отдельный датированный источник**; не заменяйте значения архивных полей молча.

## Критерии готовности нового сайта

- Свой дизайн и код; мобильная/десктопная верстка, доступная навигация с клавиатуры, подписи/alt, читабельность и контраст. Рендер без ошибок и битых **локальных** изображений; обработка отсутствующего фото. Поиск и фильтр (если заявлены) проверены в браузере.
- Явная надпись **«Архивная цена на 26.10.2026; актуальную уточняйте у продавца»** у цен, пока владелец не предоставит новый источник с датой. Не писать «в наличии» как текущий факт и не создавать фиктивную оплату/доставку; CTA может вести на индивидуальный URL Avito.
- Тексты продавца и официальные сведения бренда разделены визуально и по атрибуции. Обещания эффектов косметики и слова «оригинал» — только как архивные заявления, не гарантия от нового сайта. Состав/INCI и SPF относятся к странице производителя, маркировку конкретной партии проверять отдельно.
- Не переносить контактные/личные сведения из HTML/отзывов. Собирайте публичный сайт **в отдельную папку вывода**, включающую лишь предназначенные к показу данные и выбранные ассеты: не выкладывайте как веб-корень весь репозиторий с `snapshot.json`, исходными манифестами и отзывами. Фото брендов и продавца использовать в публичной коммерческой версии **после решения вопроса о правах**; владение магазином не означает прав на изображения брендов.
- Не менять этот архивный реестр ради дизайна; новые актуальные сведения добавлять отдельным проверяемым слоем. Запускать `python -m unittest discover -s tests -v` и `python handoff/generate.py`, затем проверять, что сгенерированный пакет не расходится с исходниками.

**Входных данных для актуального магазина всё ещё не хватает:** владелец может предоставить свежие цену, остаток, точный вариант/комплектацию для каждого из 14 товаров, оригинал фото № 4 часов и отдельную HTML-карточку лота `8350792227`. Если их пока нет, новый сайт должен честно оставаться **архивной витриной**.
