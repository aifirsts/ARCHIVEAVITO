# Beauty Supply — витрина магазина (сборка сайта)

Публичный сайт магазина: **18 страниц**, 14 лотов Avito, 150 фотографий, 5 брендов.
Собирается из `handoff/storefront.json` + манифестов аудита, публикуется в `site/public`
и загружается на **usaforru.shop** (Porkbun Static Hosting).

Сайт **не принимает оплату**, не обещает доставку и не подтверждает наличие: каждая карточка
ведёт на конкретное объявление Avito, а цены помечены датой — архивный снимок `26.10.2026`
и сообщения продавца `28.10.2026`.

## Что внутри

| Путь | Назначение |
| --- | --- |
| `site/site_config.json` | бренд, домен, hero-тексты, FAQ, подборки — контент без правки кода |
| `site/src/site.css` | дизайн-система + «магазинный» слой (hero, trust, бренды, шаги, FAQ, мини-карточки) |
| `site/src/app.js` | галерея с клавиатурой и лайтбоксом, поиск, фильтры по категории и тегам, сортировка, состояния изображений |
| `site/src/assets/` | иллюстрация для hero и OG-карточка 1200×630 (сгенерированы, не фото товара) |
| `site/build.py` | генератор: каталог, подбор, карточки, страница источников, 404, sitemap, robots, манифест |
| `site/public/` | **готовый статический сайт** (единственный веб-корень) |
| `site/tests/browser_smoke.py` | smoke-тест в Chromium (десктоп 1440×950 и мобильный 390×844) |
| `site/tests/dom/dom_smoke.js` | headless-DOM прогон в jsdom: поиск, фильтры, теги, сортировка, URL-состояние, галерея, лайтбокс, 404 — без браузера |

Тяжёлые PNG из нового архива (5 кадров галереи + фото из PDF-печати) перекодируются в JPEG q82:
публичный каталог занимает ~7,7 МБ вместо 12 МБ. В `assets/images.json` у каждого файла указаны
`source_path`, `source_sha256`, `transform` и `published_sha256`, поэтому опубликованный JPEG
прослеживается до исходного PNG с точным хешем. Иллюстрации витрины лежат отдельным ключом
`site_assets` — они не смешиваются с фотографиями товаров.

Публикуется только `site/public`: в нём нет исследовательских JSON, отзывов, исходных ZIP, HTML и
скриптов архивов. `site/src/app.js` не использует `innerHTML`: весь текст галереи и состояний ошибок
собирается через `createElement`/`textContent`, поэтому разметка из архивных данных не может быть
исполнена как HTML.

## Страницы

| Файл | Что показывает |
| --- | --- |
| `index.html` | hero + trust-полоса + бренды + каталог (поиск, категории, теги, сортировка) + прайс продавца 28.10 + подборки + 3 шага покупки + FAQ с JSON-LD |
| `podbor.html` | пять подборок по задаче и сводная таблица «архив / продавец» |
| `item/<id>-<slug>.html` | галерея с источниками, цена с датой и преимущества, CTA «Написать продавцу на Avito», похожие лоты, описание, характеристики, бренд, происхождение кадров, честные ограничения, статус |
| `sources.html` | 8 ZIP с SHA-256, слои данных, что не публикуется, домен и публикация |
| `404.html` | страница ошибки с популярными лотами |
| `sitemap.xml`, `robots.txt`, `site.webmanifest`, `CNAME`, `.nojekyll` | техническая обвязка публикации |

Слаги карточек — стабильные ASCII-адреса (`PRODUCT_SLUGS` в `site/build.py`), чтобы ссылки
не ломались при смене названия в объявлении.

## Сборка и просмотр

```bash
python -m pip install -r requirements-dev.txt   # Pillow нужен для перекодирования PNG → JPEG
python handoff/generate.py            # обновить пакет данных (детерминированно)
python site/build.py                  # пересобрать site/public
python site/build.py --check          # проверить, что сохранённая сборка совпадает с источниками
cd site/public && python -m http.server 8080 --bind 0.0.0.0
```

Откройте `http://localhost:8080/`. Сайт полностью статический: относительные пути работают
и в подпапке, и в корне домена.

## Проверки

```bash
python -m unittest discover -s tests -v          # 66 офлайн-теста: архив, пакет, сборка, ссылки, хеши, SEO, подборки
node --check site/src/app.js
npx --yes html-validate@11 "site/public/**/*.html"    # HTML5 + a11y, 18 страниц, 0 ошибок
(cd site/tests/dom && npm install) && node site/tests/dom/dom_smoke.js   # поиск, фильтры, галерея, лайтбокс
python -m pip install playwright && python -m playwright install chromium
python site/tests/browser_smoke.py               # проверки в реальном браузере, 0 ошибок консоли
```

CI (`.github/workflows/validate.yml`) прогоняет офлайн-тесты, проверяет детерминированность пакета и
сборки (`git diff --exit-code -- site/public`), собирает сайт как артефакт, запускает браузерный тест, а в
job `markup` — валидацию HTML5/a11y всех страниц и headless-DOM прогон. Публикация на хостинг — `.github/workflows/publish-porkbun.yml` (по кнопке).

## Публикация

Полный runbook — [`deploy/README.md`](../deploy/README.md). Коротко:

```bash
cp deploy/.env.example deploy/.env         # FTP-доступы из панели Porkbun
export $(grep -v '^#' deploy/.env | xargs)
python3 deploy/publish_porkbun.py --dry-run
python3 deploy/publish_porkbun.py
```

Загружать нужно **содержимое** `site/public` в корень сайта (`index.html` — в корне).
GitHub Pages в репозитории не включён; workflow `deploy.yml` оставлен как альтернатива
для превью (Settings → Pages → Source: GitHub Actions).

## Что важно знать о данных

- **Источник истины:** `handoff/storefront.json` (генерируется из `catalog.json`, `avito_audit/*` и
  `official_assets/manifest.json`). Сайт ничего не придумывает: отсутствующие фото показаны как отсутствующие.
- **Четыре слоя, которые нельзя смешивать:** фото объявления/профиля из архивных HTML, датированный слой
  `25.10.2026` (мобильные скриншоты и PDF-печати), переписка `28.10.2026` (цены и фото от продавца) и
  материалы производителей (иллюстрации и описания линеек).
- **Известные пропуски:** у часов `8296456393` нет файла позиции № 9 (страница показывает 9 кадров, в архиве 1–8);
  у лота `8350792227` есть только фото упаковки одного чехла — второй чехол лота «2 шт» не сфотографирован,
  отдельной HTML-карточки нет. Подробности: `avito_audit/ATTACHMENTS_2026_10_25.md`.
- **Права:** иллюстрации брендов принадлежат правообладателям; владение магазином не означает разрешение на их
  коммерческое использование. Иллюстрации витрины (`hero.jpg`, `og-cover.jpg`) сгенерированы и не показывают
  конкретный бренд.
- **Отзывы и личные данные** из исходного HTML не публикуются.
